## B. The Format gate

`run_step` (`scripts/verify.sh:101-151`) evals the command, captures `$?`, and counts only **exit 0** as PASS. Exit 127 is counted as **skipped**, not passed. The proof shows `5 passed, 0 skipped`, so no step took the tool-missing path.

`bun fmt --check` is **not** a missing package.json script. Bun 1.4.4 ships a builtin formatter:
```
Usage: bun fmt [flags] [...files, directories or patterns]
  -c, --check    Do not write. Exit with 1 if a file needs formatting
```
Probe in `/tmp/bunfmt-probe` with an unformatted `ugly.js`: exit 1, `2 files need formatting`; the file was not rewritten. So `--check` is a real gate and can fail.

In the dirty root: exit 0, `All 396 files are formatted`, 0.047s. The proof's `✔ 0.0s` is real, not a rounding artifact of a no-op.

**But the green is scope-narrowed, and the proof is worktree-scoped:**
- Root/worktree `.prettierignore` adds `.oo/` (root diff replaces `.openorchestrate/` with `.oo/`; worktree adds `.oo/`).
- On clean HEAD (`git archive origin/main`), `bun fmt --check` exits **1** with **11 tracked files** needing formatting: 9 `.oo/plans/*.md` and 2 `.oo/proof/bgcolor-2026-11-17/*.json`.
