# docs/pyne/enduser/guides

# Concepts

* [CLI Guide](cli.md) - Use the pyne Click CLI to check, format, lint, compile, run, optimize, prewarm, fetch data, and more.
* [Editors & LSP](editors.md) - Wire pyne-lsp into VS Code, Neovim, Zed, Emacs, Helix, and other LSP clients for diagnostics, completion, hover, and formatting.
* [Evaluate Scripts](evaluate-scripts.md) - Run Pine expressions and multi-bar scripts with literaleval, pynescript.runtime.Runtime (libraries=, timeoutseconds, mode), data providers, and strategy events.
* [Library API](library-api.md) - Embed pynescript: parse, dump, unparse, walk, transform, and lint Pine Script™ from Python.
* [Pro API Usage](pro-api-usage.md) - Call the PYNE Flask Pro API as a consumer: health, /run, /run/batch, /optimize, chart preview, indicator preview, quick backtest, and auth.
* [Troubleshooting](troubleshooting.md) - Diagnose pynescript install, parse, lint, evaluation, LSP, data providers, and Pro API failures with concrete checks.
