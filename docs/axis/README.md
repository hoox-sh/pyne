# AXIS docs moved

**https://github.com/jango-blockchained/axis**

```bash
git clone https://github.com/jango-blockchained/axis.git ../axis
```

Local path often: `/home/jango/Git/axis` (or `/mnt/data/home/jango/Git/axis`).

default calculation engine AXIS talks to in local dev.
