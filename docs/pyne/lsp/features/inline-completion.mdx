# Inline completion

## Abstract

`textDocument/inlineCompletion` (LSP 3.18) offers one ghost-text suggestion for a curated set of builtins when the cursor sits immediately after an empty `(` — e.g. `ta.sma(` suggests `close, 14)`. It is deterministic and model-free; no network calls, no speculation.

## Interface surface

- Method: `textDocument/inlineCompletion`
- Capability: `inline_completion_provider` (`InlineCompletionOptions`)
- Handler: `features/inline_completion.py` → `handle_inline_completion`
- Setting: `inlineCompletionEnabled` (default `false` — opt-in; never competes with the normal completion list)

Behavior notes:

- Fires only when the argument list is empty and no `)` follows on the line.
- Suppressed inside comments and strings (including unterminated ones at the cursor).
- Returns `None` for unknown callees and for non-empty argument lists.
- Works on the line prefix only, so it responds while the buffer does not parse.
