# MCP Tools

## Abstract

Machine-oriented catalog for the **PYNE MCP server** (`pyne-mcp` / `pyne mcp`) and the in-process CLI (`pyne mcp call TOOL`, plus `pyne execute` / `symbols` / `parity` / `diagnostics` / `builtin`). Names match `src/pynescript/mcp/catalog.py`. Guide: [MCP (agents)](/pyne/docs/enduser/guides/mcp). Tools return JSON `{ok, ...}`. Inputs accept `source` (preferred) and/or `path`. Stdio serving needs `hoox-pyne[mcp]`; `call` / `execute` do not.

| Tool | CLI | Notes |
| --- | --- | --- |

| `pyne_unparse` | `pyne parse-and-unparse` | round-trip source |

| `pyne_compile` | `pyne compile` | `emit` prints generated Python |
| `pyne_prewarm` | `pyne prewarm` | Numba / IR warm |
| `pyne_run` | `pyne run` | synthetic OHLCV, compile pipeline |
| `pyne_optimize` | `pyne optimize` | `space` object or `space_json` |
| `pyne_data` | `pyne data` | default provider `mock` |
| `pyne_download_builtins` | `pyne download-builtins --list` | list only (network) |
| `pyne_runner_deploy` | `pyne runner deploy` | POST `/scripts` |
| `pyne_runner_list` | `pyne runner list` | |
| `pyne_runner_show` | `pyne runner show` | |

Runner tools read `PYNE_API_URL` / `ADMIN_TOKEN`. They never echo tokens or webhook URLs.

## Deeper tools

These also run from the CLI (`pyne mcp call TOOL`, plus first-class commands where listed).

| Tool | CLI | Result |
| --- | --- | --- |
| `pyne_parse` | `pyne mcp call parse PATH` | `{version, kind, title, errors[{line,column,message}]}` |
| `pyne_symbols` | `pyne symbols PATH` | functions, types, enums, `input.*`, plots, `strategy.entry` |
| `pyne_execute` | `pyne execute PATH` | `Runtime.run`; caller `ohlcv` rows; truncated plots; strategy extras |
| `pyne_parity` | `pyne parity PATH` | interpret vs compile last values (`rtol=1e-5`, `atol=1e-6`) |
| `pyne_hover` | `pyne mcp call hover PATH --arg line=0 --arg character=0` | markdown at 0-based `line` / `character` |
| `pyne_complete` | `pyne mcp call complete PATH` | completion items at cursor |
| `pyne_signature` | `pyne mcp call signature PATH` | signature help for the enclosing call |
| `pyne_builtin` | `pyne builtin ta.sma` | `builtin_metadata.json` row (`ta.sma`, …) |
| `pyne_diagnostics` | `pyne diagnostics PATH` | parse errors + lint in one list |
| `pyne_axb1` | `pyne mcp call axb1` | AXB1 encoder vs golden vectors (hex-exact) + fnv1a32 + reject rules |
| `pyne_sessions` | `pyne mcp call sessions` | pooled live sessions: anchor vs store window, zombie suspects |

`pyne_execute` plot cells: `{len, last, na_count, sample}` (`sample` default 8, max 64). Timeout default 30s, cap 120s. Bars cap 5000.
