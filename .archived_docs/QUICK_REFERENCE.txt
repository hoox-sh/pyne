## 🏗️ Implementation Template

For **every function**, follow this pattern:

```python
# 1. Create handler
def _handle_function_name(self, args: list[Any]) -> Any:
    """Return appropriate data structure for this function"""
    arg1 = args[0] if len(args) > 0 else default_val
    arg2 = args[1] if len(args) > 1 else default_val
    # ... validate inputs, process, return result

# 2. Register in dispatch map
def _build_builtin_map(self) -> dict[str, BuiltinHandler]:
    return {
        "function_name": self._handle_function_name,
        "function.subname": self._handle_function_subname,
    }

# 3. Write test
def test_function_name():
    evaluator = NodeLiteralEvaluator()
    result = evaluator.eval_call("function_name", [arg1, arg2])
    assert result == expected_value

# 4. Update docs
# Change ❌ to ✅ in docs/pinescript_implementation_status.md
```

## 🔑 Key Decisions

| What | How | Why |
|------|-----|-----|
| **Return type for input()** | Dict with metadata | Simulates Pine's declaration-time evaluation |
| **Return type for request()** | List (series) of values | Represents historical time-series data |
| **Drawing objects** | Python dataclasses | Clear structure, easy to extend |
| **Object registry** | Global list in evaluator | Matches Pine's .all collection behavior |
| **Test coverage** | 95%+ | Catch regressions early |
