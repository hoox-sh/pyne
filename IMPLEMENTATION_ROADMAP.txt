ARCHITECTURE OVERVIEW
================================================================================

The evaluator uses modular dispatch pattern:

  NodeLiteralEvaluator (coordinator)
    ├── BaseEvaluator
    ├── LiteralEvaluator
    ├── ExpressionEvaluator
    ├── BuiltinEvaluator -> dispatches to:
    │   ├── numeric.py (math.*)
    │   ├── strings.py (str.*)
    │   ├── arrays.py (array.*)
    │   ├── technical.py (ta.*)
    │   ├── utility.py
    │   └── plotting.py
    ├── StatementEvaluator
    └── NameEvaluator

Adding new functions:
  1. Create module in src/pynescript/ast/evaluator/builtins/
  2. Implement _builtin_dispatch mapping
  3. Register handlers with namespace (e.g., "input.bool")
  4. Mix into BuiltinEvaluator via inheritance
  5. Add comprehensive tests
